# Example Workout PDFs

Example no-equipment workout PDFs can be downloaded from [Darebee's no-equipment workouts page](https://darebee.com/no-equipment-workouts.html).

Download the PDFs you want to use and place them in this directory before running the project's ingestion command. Check Darebee's current terms before redistributing any downloaded material; do not commit copies here unless redistribution is permitted.
